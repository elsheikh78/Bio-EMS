# BIO EMS

Environmental Monitoring System for Pharmaceutical Cold Rooms and Warehouses.

## Features

- Multi-Site Support
- Cold Rooms
- Dry Stores
- Glycol Probe Support
- Temperature & Humidity Monitoring
- MQTT Communication
- InfluxDB Storage
- SQLite Configuration Database
- SMS Backup Alarm
- Email Notifications
- Multi-language (Arabic / English)
- User Roles
- Dashboard & Reports
