# First Screen

The first screen displayed after login is the Asset List.

The dashboard is not the default landing page.

---

# Why

Users think in terms of business assets, not hardware devices.

Typical examples include:

- Cold Rooms
- Freezers
- Warehouses
- Incubators
- Clean Rooms

Users want to know the status of these assets first.
