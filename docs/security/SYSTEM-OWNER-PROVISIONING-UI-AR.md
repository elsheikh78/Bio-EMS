# تشغيل تفعيل System Owner من الواجهات

## النتيجة التشغيلية

أصبح تفعيل حساب `SYSTEM_OWNER` دورة مرئية من أداتين منفصلتين:

1. **BIO-EMS System Owner Provisioning** على جهاز العميل.
2. **BIO-EMS Manufacturer Owner Signer** على جهاز الشركة المنفصل عن الإنترنت.

لا تنشئ واجهة العميل الحساب ولا تختار بياناته، ولا يصل المفتاح الخاص للشركة إلى جهاز
العميل. الحساب لا يُنشأ إلا بعد استيراد حزمة صحيحة موقعة ومرتبطة بهوية نفس التثبيت.

## على جهاز العميل

شغّل من قائمة Start:

`BIO-EMS System Owner Provisioning`

تطلب الأداة صلاحية Administrator ثم تعرض Installation ID.

1. اضغط **Create commissioning request**.
2. احفظ ملف JSON الجديد.
3. انقل ملف الطلب فقط إلى جهاز الشركة.

الطلب لا يحتوي كلمة مرور أو مفتاحًا خاصًا.

## على جهاز الشركة Offline

من نسخة المصدر المضبوطة شغّل:

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\installer\windows\Invoke-ManufacturerOwnerSigner.ps1
```

ثم:

1. اختر ملف الطلب.
2. اختر مفتاح Ed25519 الخاص المشفر.
3. تأكد من Key ID المعتمد.
4. اختر اسم مستخدم System Owner.
5. أدخل كلمة مرور قوية وأكدها.
6. أدخل عبارة مرور المفتاح الخاص محليًا.
7. احفظ حزمة التفعيل الموقعة.

لا تنقل المفتاح الخاص أو عبارة مروره أو نسخة المصدر إلى جهاز العميل.

## استيراد الحزمة

خلال مدة صلاحية الحزمة الافتراضية، وهي 15 دقيقة:

1. ارجع إلى أداة **BIO-EMS System Owner Provisioning** على جهاز العميل.
2. اضغط **Import signed activation package**.
3. اختر الحزمة الموقعة.
4. تنتظر الأداة إيقاف Backend مؤقتًا، والتحقق من التوقيع، وإنشاء الحساب، ثم إعادة الخدمة.

الحزمة تُرفض إذا كانت منتهية، معدلة، مستخدمة سابقًا، موقعة بمفتاح غير معتمد، أو مرتبطة
بتثبيت آخر.

## تفعيل MFA والدخول

افتح:

```text
https://localhost/system-owner/login
```

أدخل اسم المستخدم وكلمة المرور اللذين تم اختيارهما في أداة الشركة. في أول دخول تظهر
واجهة QR. امسحها بتطبيق Authenticator، أدخل أول رمز من ستة أرقام، ثم سجل الدخول مرة
أخرى بكلمة المرور والرمز الحالي.

## ضوابط الأسرار

- لا تُرسل كلمة مرور Owner أو TOTP أو عبارة مرور المفتاح في البريد أو المحادثات.
- لا تنسخ المفتاح الخاص إلى جهاز العميل أو GitHub أو CI أو Setup.
- احذف نسخ النقل المؤقتة للطلب والحزمة وفق سجل عملية التفعيل.
- لا تستخدم حزمة منتهية أو تعِد إصدارها لتثبيت مختلف.
