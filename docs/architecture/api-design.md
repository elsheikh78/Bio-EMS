# API Design

Version: 1.0

---

## Purpose

This document defines the REST API exposed by the BIO-EMS Backend.

The API is responsible for:

- Site Management
- Asset Management
- Device Management
- Monitoring Point Management
- Alarm Management
- User Management
- Authentication
- System Configuration
