# Project Ideas

## Deferred Ideas

### Measurement Entity

Status: Proposed

Description

Consider introducing a Measurement entity separate from Telemetry.

Motivation

Telemetry represents the raw incoming communication.

Measurement represents processed engineering values used by the system.

Decision

Deferred until the Devices, Channels and Sensors modules are completed.
