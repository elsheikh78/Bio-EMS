# ADR-006

## Title

Domain Naming Convention

## Status

Accepted

## Date

2026-07-21

## Decision

The project adopts the following domain names as the official naming convention.

- Site
- Room
- Monitoring Point
- Sensor
- Device
- Telemetry
- Alarm
- Notification

These names will be used consistently across:

- Database
- Source Code
- REST APIs
- MQTT
- Documentation
- Diagrams

No alternative names shall be introduced without a new ADR.

## Rationale

Keeping the terminology stable improves:

- Readability
- Documentation consistency
- API consistency
- Maintainability
- Team communication
