# Sprint 09 – REST API Foundation

## Version

v0.8.0

---

# Objective

Introduce the first production-ready REST API layer for the BIO-EMS Backend.

This sprint establishes the standard architecture for all future APIs.

---

# Completed Features

## Alarm Repository Enhancement

Implemented additional repository methods:

- getAll()
- getActive()
- getById()
- acknowledgeAlarm()

---

## Alarm Service Enhancement

Added:

- getAlarms()
- getActiveAlarms()
- getAlarmById()
- acknowledgeAlarm()

Business rules moved into the Service layer.

---

## Alarm Controller

Created:

```
controllers/alarm.controller.ts
```

Implemented endpoints:

- GET /alarms
- GET /alarms/active
- GET /alarms/:id
- POST /alarms/:id/acknowledge

---

## Alarm Route

Created:

```
routes/alarm.route.ts
```

Registered inside app.ts.

---

## Error Handling

Integrated AppError.

Business validation now resides inside the Service layer.

Error responses are generated by the global Error Middleware.

```
docs/development/API-Development-Standard.md
```

Defines the mandatory workflow for all future APIs.
